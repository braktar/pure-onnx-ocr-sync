# タスク概要
モデル・辞書ロード設定を管理する `OcrEngineBuilder` を実装し、利用者向けの構築 API を完成させる。

## 要件
- モデルパスやデバイス設定などのビルダー API を設計する
- 入力検証とエラー型の伝達を整備する
- モデル・辞書の遅延ロード戦略を定義する
- ユニットテストで代表的な構築パターンを検証する
